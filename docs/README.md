# Pest-Free Northland documentation

This folder contains documentation for Pest-Free Tracker.

- [API documentation](API_DOCUMENTATION.md) - endpoints, authentication, validation, examples and error handling.
- [User manual](USER_MANUAL.md) - ordinary-user and coordinator workflows, including PWA and offline use.
- [Technical documentation](TECHNICAL_DOCUMENTATION.md) - architecture, database, setup, tests and deployment; includes architectural, use-case, class and sequence diagrams.
- [Existing entity relationship diagram](erd.md) - database relationships.

The project uses FastAPI and a browser-based PWA frontend. The application serves both from the same origin in the normal setup.
